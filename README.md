# NEXO — Sistema de Gestão Comercial

O Nexo é um projeto de sistema de gestão comercial desenvolvido em Python, com banco de dados SQLite.

O objetivo é desenvolver uma aplicação para auxiliar no gerenciamento de produtos, fornecedores, estoque e operações comerciais.

## Tecnologias utilizadas

- Python
- SQLite
- Git e GitHub

## Funcionalidades implementadas

### Produtos
- Cadastro de produtos
- Listagem de produtos
- Consulta de estoque
- Atualização de produtos
- Exclusão de produtos
- Validação de dados

### Fornecedores
- Cadastro de fornecedores
- Listagem de fornecedores
- Consulta por CNPJ
- Atualização de fornecedores
- Exclusão de fornecedores

## Estrutura do projeto

- `main.py` — Menu principal
- `database.py` — Conexão e estrutura do banco de dados
- `produtos.py` — Gerenciamento de produtos
- `fornecedores.py` — Gerenciamento de fornecedores

## Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute no terminal:

python main.py


O banco de dados SQLite será criado automaticamente na primeira execução.
